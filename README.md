# STIGMAT — отдельная контактная страница

Откройте `index.html` двойным щелчком. Вся папка самостоятельна; работает без интернета, сервера, JavaScript и сборки.

- `index.html` — текст, логотип и контактная ссылка.
- `styles.css` — отдельные стили, включая мобильную версию.
- `assets/logo.svg` — оригинальный логотип STIGMAT.
- `assets/favicon.ico` — значок сайта.

Нажатие `contact@stigmat.eu` открывает почтовое приложение через `mailto:`. Письмо отправляет сам посетитель. Страница не собирает данные, не оформляет подписку и не отправляет сообщения автоматически.

Логотип, подпись For enquiries & collaborations и email объединены в блок по центру экрана. Белый фон, адаптивная вёрстка и футер внизу экрана. Текст можно заменить прямо в HTML. Для размещения на хостинге достаточно скопировать содержимое этой папки.

## Перелив логотипа

Только нейтральные серые, серебристые и белые оттенки. Блики перетекают по буквам поверх тонкой рельефной текстуры, сохраняя оригинальную форму логотипа. Эффект не зависит от прокрутки и не требует JavaScript: CSS-анимация `wordmark-flow` и встроенный SVG-фильтр `liquid-metal`. Один проход занимает 8 секунд, затем движение плавно меняет направление. При системной настройке уменьшения движения остаётся неподвижная серебристая заливка.
